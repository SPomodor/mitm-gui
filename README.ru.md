# mitm gui

**by SPomodor** · **[English](README.md)**

Настольный интерфейс для **mitmproxy**: просмотр HTTP/HTTPS, подключение телефона через WireGuard, подмена ответов и Python-сценарии. Компактные таблицы, инспектор запросов, сохраняемая история, русский и английский интерфейс.

Проект создан **SPomodor при помощи OpenAI Codex**. Это независимый интерфейс, не официальный продукт команды mitmproxy.

## Скачать

[Готовые сборки](https://github.com/SPomodor/mitm-gui/releases) · [Сборки GitHub Actions](https://github.com/SPomodor/mitm-gui/actions/workflows/build.yml)

Поддержанная сборка — **Windows x64**, файл `mitm-gui-<версия>-win-x64.exe`. Python и Node.js пользователю не нужны. Если релиза ещё нет, откройте успешный запуск Actions и скачайте артефакт `mitm-gui-windows-x64`. Сборка не подписана сертификатом; Windows может показать предупреждение об неизвестном издателе.

macOS пока не проверена. Для будущего переноса есть команда сборки на Mac; Windows CI не создаёт macOS-приложение.

## Возможности

- HTTP/HTTPS-прокси и WireGuard с QR-кодом для подключения телефона.
- Выборочная расшифровка SSL по доменам/IP и порту.
- История зашифрованных соединений: адрес, время и объём данных.
- Поиск, фокус по хостам, инспектор Request/Response, оригинал и изменённая версия.
- Rewrite заголовков, query, Host, Path, URL, статуса, текста и полей JSON.
- Map Local, блокировка запросов, порядок правил и независимые окна редакторов.
- Python-скрипты с условиями, переменными и обработчиками запросов/ответов.
- Библиотека сценариев, этапы, подсветка, Tab, поиск, импорт/экспорт `.py`.
- Архив сессий, HAR и отдельный режим сводок соединений для Charles.
- Изменяемые размеры панелей, светлая/тёмная тема, русский/English/Авто.

## Быстрый старт

1. Запустите приложение. По умолчанию включается HTTP-прокси и запись трафика.
2. Откройте «Подключить устройство», выберите HTTP-прокси или WireGuard.
3. Для HTTPS установите сертификат через `mitm.it` и включите доверие на устройстве.
4. Откройте своё приложение или сайт — запросы появятся в «Трафике».
5. В «Сценариях» нажмите «Пример», примените и включите его. Откройте `http://example.com/api/hello` через прокси.

«Запись» управляет сохранением истории; «Перехват» запускает/останавливает слушатели. Системный прокси, доверие CA и брандмауэр приложение автоматически не меняет. После запуска применённый сценарий выключен.

## Разработка

Нужны Node.js 24, Python 3.13 и Git.

```powershell
git clone https://github.com/SPomodor/mitm-gui.git
cd mitm-gui
npm run setup
npm run dev
```

```powershell
npm run build
npm test
npm run test:format
npm run test:ui
npm run package
```

Portable-файл появится в `release/`. `.venv`, `node_modules`, данные перехвата и готовые бинарники не коммитятся.

## GitHub Actions и релизы

Push и pull request запускают тесты, сборку движка, проверку упакованного приложения и создание EXE. Ручной запуск: Actions → Build and test → Run workflow. Готовые файлы — в артефактах успешного запуска.

Тег, совпадающий с версией `package.json`, например `v0.9.0`, после успешной сборки публикует GitHub Release с EXE и SHA-256. Используется встроенный `GITHUB_TOKEN` Actions; отдельный токен не требуется.

## Ограничения и данные

Работайте с приложениями и устройствами, которые вы вправе проверять. Не публикуйте реальные HAR, CA-ключи, WireGuard-профили и токены в Issues.

HTTPS требует доверия CA; pinning настраивается в debug-сборке вашего приложения. Без расшифровки путь и содержимое HTTPS недоступны. UDP/QUIC/DTLS экспериментальны; IPv6 WireGuard ограничен. Python-скрипты имеют доступ к файлам и системе, проверка выполняет код верхнего уровня.

Приложение ранее называлось CHLS. Старые профили и `from chls import ...` поддерживаются; для новых скриптов используйте `from mitm_gui import ...`.
